# Use Case: Настройка и исполнение правила авто-перевода

**Актор:** Клиент (через мобильное приложение)

## Основной поток

1. Клиент открывает экран «ФинАвтопилот».
2. Указывает: источник (счёт для зачисления), получатель (накопительный счёт),
   тип правила (процент/фикс), значение.
3. Система валидирует параметры (процент ≤ 100, сумма > 0, счёт получателя активен).
4. Система сохраняет правило со статусом «Активно».
5. При следующем поступлении на счёт-источник система рассчитывает сумму перевода
   и инициирует перевод.
6. Клиент получает push-уведомление о выполнении.

## Альтернативный поток A1: Недостаточно средств после резервирования

- 5а. Система видит, что после перевода баланс источника станет ниже минимального порога.
- 5б. Перевод не выполняется, правило помечается как «Пропущено».
- 5в. Клиент получает уведомление с причиной.

## Альтернативный поток A2: Счёт получателя заблокирован

- 5а. Система получает ошибку от сервиса счетов.
- 5б. Правило переводится в статус «Приостановлено».
- 5в. Клиент получает уведомление с просьбой обновить данные.
