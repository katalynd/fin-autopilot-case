# fin-autopilot-case
проектирование сервиса автоматического распределения доходов
(автоматический перевод части поступлений на накопительный или брокерский счёт).

## Бизнес-задача

Клиент хочет автоматически переводить часть поступающих доходов
(зарплата, переводы) на накопительный или брокерский счёт.
Сейчас это делается вручную.

Нужно спроектировать сервис, который по заданному правилу
(процент от поступления или фиксированная сумма) инициирует перевод
между счетами клиента сразу после зачисления средств.

### Ограничения
- Перевод не должен приводить к отрицательному балансу.
- Правило можно приостановить.
- Все действия логируются.
